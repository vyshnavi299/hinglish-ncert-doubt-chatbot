# Hinglish NCERT Doubt Chatbot

AI chatbot designed for Indian school students who ask doubts in Hinglish or Tanglish.

## Problem
Most AI learning tools respond in formal English which many students struggle to understand.

This chatbot understands code-mixed language and explains concepts like a senior student.

## Features

• Hinglish / Tanglish doubt solving  
• NCERT Class 9–10 Science & Math support  
• Voice explanation using Text-to-Speech  
• Practice question generator  
• Concept explanation with Indian examples  

## Tech Stack

Python  
Streamlit  
OpenAI API  
gTTS (Text-to-Speech)

## How to Run
pip install -r requirements.txt
streamlit run app.py
